# Project 01 - Basic Login Page

## Purpose
Created a simple login page using HTML and CSS to practice front-end fundamentals.

## What I Learned
- HTML forms
- Input fields
- Labels and placeholders
- Buttons
- CSS styling
- Layout and positioning

This project is the first step toward understanding how login systems work.

In the future, I plan to:
- Add JavaScript validation
- Add a backend

- Practice identifying and exploiting vulnerabilities in a safe lab environment
